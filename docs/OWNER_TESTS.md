# Tests that need the owner at the device

**FIRST: the device is powered down (recovery test, 2026-11-07 ~16:00).** I staged a deliberately hung image to test tools/homtom-recover; it hung before init.sh could set INFORM0=5, so the watchdog reset made the bootloader power the unit down. Press and hold the power key until the screen lights; the bootloader should pass through the storage window and the recovery job (already running on the Mac, log in .runtime/recover.log) restores the known-good image (ladder-bt2) and boots it. If nothing happens within ~2 minutes, run `tools/homtom-recover 600` in a terminal and press the power key again. The kernel fix (INFORM0=5 as soon as the kernel starts) is built into the next image.

Run from the repo root on the Mac (device in LINUX state; the HA bridge keeps running in the background).

1. **Touch calibration (5 points).** `tools/homtom-touch-run cal` — press each crosshair with a fingernail or stylus when it appears, firmly, and keep hands off the screen for the first second. It prints the exit code and `touch.cal`. Then `tools/homtom-touch-run targets`, `draw`, `drag`, `slide`. If a press does not register: `tools/homtom-touch-run raw` (idle should read about 1022, a press should drop it by hundreds), then `scan --kmsg` (see workspace/touch/README.md).
2. **Backlight.** `tools/homtom-sh '/bin/homtom-bl 255'` (bright), `'/bin/homtom-bl 60'` (dim), `'/bin/homtom-bl 0'` (off), then `'/bin/homtom-bl 255'`. Tell me what changes. Never leaves GPB0 off permanently: run `homtom-bl 255` afterwards.
3. **GUI.** `tools/homtom-sh 'echo "battery_pct_est=73" > /tmp/homtom-ui.txt; /bin/homtom-gui -1 -f /tmp/homtom-ui.txt' 15` (see workspace/gui/README.md); the text console is muted while it runs.
4. **Sound.** The first tool (homtom-snd) was silent because it never switched the speaker amp on and used mute-level volumes. Use the fixed one: `tools/homtom-sh '/bin/homtom-snd2 --hz 1000 --secs 4 --vol 117 --iiscon 1 > /tmp/t.txt 2>&1' 20` (stock volume 117 is fairly loud; try --vol 90 first). Microphone: `tools/homtom-sh '/bin/homtom-snd2 --mic 3 > /tmp/m.txt 2>&1' 20` while talking or clapping, then read /tmp/m.txt over FTP.
5. **Bluetooth pairing (Mac).** `tools/homtom-sh 'touch /tmp/bt.pair'`, then macOS System Settings > Bluetooth > connect "homtom"; PIN is in `.runtime/bt_pin` (never committed). After pairing, `ls /dev/cu.*` on the Mac should list a homtom serial port; `screen /dev/cu.<name>` then type `status`. Logs on the device: `/tmp/btd.log`; `hcictl-info 0` shows hci0 flags. iPhone cannot open a serial port without MFi; it only needs to see the device.
6. **LCD check.** Heartbeat line every 30 s on the console; splash via `tools/homtom-draw brand/splash/homtom-splash-semibold.fb`.

Note: the pairing window (`touch /tmp/bt.pair`, or the "BT visible" button on the Tools page, docs/OWNER_TOOLS.md) closes after 300 s (homtom-btd; `echo 600 > /tmp/bt.pair` asks for another length, 30..1800 s); open it right before pairing.
