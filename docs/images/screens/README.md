# Screenshots

All images are 480x272, the native panel size. Files prefixed `device-` are real on-device screenshots taken with `tools/devtools/homtom-shot`. Files prefixed `render-` are host-side renders of the GUI on a computer, not photos or captures of the unit.

| File | What it shows | Source |
|---|---|---|
| `device-office.png` | Office page: heating setpoint with plus and minus, an "All lights" slider, presence, CO2, temperature and humidity, and a vent entry | on-device screenshot |
| `device-office-early-ui.png` | Earlier Office page with tile layout, light slider, sensor tiles and a bottom tab bar (Office, Home, Controls, GPS, System, Tools) | on-device screenshot |
| `device-system-menu.png` | System menu with tiles for Display and sound, GPS, Bluetooth, Sound test, Time and date, and Device | on-device screenshot |
| `device-tools.png` | Tools page: GPS aid, Bluetooth visible, Mic test, Beep, GPS power switch and a Storage mode button | on-device screenshot |
| `device-home-battery-gps.png` | Home page: battery at 100 % and charging, ambient light, GPS status "No fix" | on-device screenshot |
| `device-controls-sliders.png` | Controls page: backlight and volume sliders, Beep button, Mute switch | on-device screenshot |
| `device-system-status.png` | System page: device status list, battery gauge, Away switch, Storage mode button | on-device screenshot |
| `device-gps-no-fix.png` | GPS page with no fix, 0 satellites and empty altitude and HDOP | on-device screenshot |
| `render-storage-mode-confirm.png` | "Reboot to storage mode?" confirmation dialog over the System page | host-side render |
| `render-scenes.png` | Scenes page with Lights on, Lights off, Good night, Dim, Bright and an Away switch | host-side render |
| `render-gps-fix.png` | GPS page with a fix, 7 satellites and invented sample values | host-side render |
